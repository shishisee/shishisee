# 별과 우주 3D 관측소 — 인수인계 메모 (Claude용)

중1 과학 「별과 우주」 단원용 3D 웹앱. 왼쪽 = 우주에서 본 실제 운동, 오른쪽 = 서울에서 본 겉보기 운동.

## 실행 / 빌드
- `npm install` → `npm run dev` (개발), `npm run build` → `dist/` (정적 파일, 그대로 배포 가능)
- Vite + TypeScript + three.js. 프레임워크 없음.

## 구조
| 파일 | 역할 |
|---|---|
| src/main.ts | 화면 틀, 탭 전환, 한 캔버스에 두 화면(scissor) 그리기, 인트로 |
| src/astro.ts | 천문 계산(태양·달 위치, 항성시, 좌표 변환, 황도 12궁 경계) |
| src/sky.ts | 별(5044개, 6등급까지)·별자리 선·은하수 셰이더·별 궤적 |
| src/bodies.ts | 지구(낮/밤/구름/대기 셰이더), 달, 태양 |
| src/ground.ts | 지상 시점 하늘(대기 색, 지평선, 방위, 라벨, 시점 조작) — 모든 모듈이 공유 |
| src/observer.ts | 지구 위 관측자 표시(지평면 + 바라보는 방향 화살표) |
| src/modules/*.ts | 일주 운동 / 연주 운동·황도 12궁 / 달의 위상 / 자유 관측 |
| src/data/sky.json | scripts/build-data.py 로 d3-celestial(BSD) 자료에서 만든 별 자료 |
| public/tex/ | three.js 예제 행성 텍스처 |

## 시간 모델
- 수업용으로 '지방 태양시'를 씀: 12시 = 태양 남중, 0시 = 자정. LST = 태양 적경 + (시각-12)×15°.
- 자유 관측만 실제 한국 시각(KST)과 실제 항성시를 씀.

## 배포
- 아직 배포 안 함 (선생님 확인 후 배포하기로 함).
